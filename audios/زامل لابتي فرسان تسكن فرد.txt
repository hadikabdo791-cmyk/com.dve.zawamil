زامل”لابتي فرسان تسكن فرد”

أداء/ عيسى الليث

كلمات / عبدالله عيظة الرزامي

•••••••••••••••
لابــتـي فــرســـان تســــكـن فـــرد
لبـــت إبن البــــــدر فـي كل ساعه
( تصـلي الغـازي بحـــد الســلاح )

قــالـــت أبشــر بي وحــنا الســنـد
بعـــد أبوجـبريل رمـــز الشـجــاعه
( ذاك قــايـدنا وحـــنا له جـــناح )

كـلــــنا نفــــديـــك نســـل الأســـد
نـطــــرد المـحـــتـل نقـطــع ذراعه
( بالـبــنـادق بالـســـلال الـمــلاح )

بـــــر والإ بـحـــــر عــــادت جـــــد
ســيدي نـفــديك سمـــعاً وطــاعه
( كـلـــنا نـهــواء دروب الـكــفـاح )

بــــالـــــولاء لله دايـــــــــم أبــــــد
نـتــبـع آل البـيـت من دون رجــعه
( في سفـينة نــوح عــز وفــلاح )
